# SWYNEX – Retail Store Sales Data Cleaning

## Project Overview
Cleaned and prepared a retail store sales dataset for data analysis as part of the SWYNEX Data Analyst Internship.

## Dataset
Retail Store Sales dataset containing transaction, customer, product, sales, payment, location, and date information.

## Data Cleaning Performed
- Replaced missing `Item` values with `Unknown`.
- Removed rows with missing `Price Per Unit`.
- Removed rows with missing `Quantity`.
- Removed rows with missing `Total Spent`.
- Replaced missing `Discount Applied` values with `FALSE`.
- Removed duplicate records.

## Result
- Original records: 12,575
- Cleaned records: 11,362

## Tools Used
- Microsoft Excel
- CSV

## Purpose
The cleaned dataset is prepared for further analysis and dashboard creation.
